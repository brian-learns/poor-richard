# Poor Richard
---
<i>A Reference Library for Agents</i>

If you give an agent access to authoritative information, it can figure out how to use it to answer questions.

This project aims to explore limits of this phenomena by giving tools to agentic and human users to provide a reference library or sorts.

The project, as it sits today, has been largely built by agents.

The agent wanted to add a keyword search, and thinking that sounded interesting, I let it proceed.

I think the way the --ask functionality is now though is a little confused / confusing for agentic users.

An agentic user of poor-richard can be thought of as a reference librarian.  A library patron comes up to the desk, and asks a question.

The reference librarian then analyzes the question uses their knowledge of the collections and cataloging practices to either select the correct reference 
or search for references that can be used to find the answer.

The present affordances of poor richard cause the agentic user to type the human user's question directly into the keyword search.

Rather than tempting an agentic-user into asking the user's question into a keyword index, how alter the design to reinforce a two-stage analysis?
